# 地図表示API マニュアル

座標を指定すると、その位置を中心にした地図をブラウザに表示します。
中心の近くにあるSOTA山岳・POTA公園も、マーカーで一緒に表示します。
認証は不要です。

## 使い方

ブラウザのアドレスバーに、次のURLを入力します。

```
https://sotaapp2.fly.dev/api/v2/map?lat=35.8574&lon=138.9442
```

`lat`(緯度)と`lon`(経度)は必須です。どちらかが欠けると、エラー(400)になります。

## 表示内容

| 表示 | 内容 |
|------|------|
| 中心のピン | 指定した座標、グリッドロケータ(メイデンヘッド)、`label` |
| 青い丸 | SOTA山岳(コード・名称・標高・ポイント・所在地・距離) |
| 緑の丸 | POTA公園(コード・名称・所在地・距離) |
| 破線の円 | 近傍を探した範囲(`radius`) |
| ヘッダ | 座標、グリッドロケータ、Google Maps / OSM / 地理院地図へのリンク |

- 近い順に最大20件を表示します。
- 近い5件は、ポップアップが最初から開いています。残りは丸をクリックすると開きます。
- 背景は、既定で国土地理院の地図(日本国内のみ)です。

## パラメータ

| パラメータ | 既定値 | 説明 |
|-----------|--------|------|
| `lat` | (必須) | 緯度。-90〜90 |
| `lon` | (必須) | 経度。-180〜180 |
| `zoom` | `15` | ズームレベル。1〜19(地理院タイルは18まで) |
| `label` | なし | 中心ピンに表示する名称。100文字以内 |
| `tile` | `gsi` | `gsi` = 地理院タイル(日本国内のみ)、`osm` = OpenStreetMap |
| `refs` | `true` | `false` にすると、近傍のSOTA/POTAを表示しない |
| `radius` | `1000` | 近傍を探す半径。単位はメートル。1〜10000 |
| `embed` | `false` | `true` にすると、ヘッダを省略する(iframe用) |

## 例

富士山を、ラベル付きで、ズーム13で表示します。

```
/api/v2/map?lat=35.360556&lon=138.727778&zoom=13&label=富士山
```

半径を5kmに広げて、周辺の山・公園を探します。

```
/api/v2/map?lat=35.8574&lon=138.9442&radius=5000
```

日本国外の座標は、`tile=osm` を付けます。地理院タイルは日本国外では表示されないことがあります。

```
/api/v2/map?lat=47.0&lon=8.0&tile=osm
```

近傍を出さず、座標だけを確認します。

```
/api/v2/map?lat=35.8574&lon=138.9442&refs=false
```

## 他のページに埋め込む

`embed=true` を付けると、ヘッダのない地図だけのページになります。

```html
<iframe src="https://sotaapp2.fly.dev/api/v2/map?lat=35.8574&lon=138.9442&embed=true"
        width="600" height="400" style="border:0"></iframe>
```

## 自分で地図を描く(JSON)

`/api/v2/map/view` は、同じパラメータで、地図を描くための情報をJSONで返します。
独自の地図画面を作る場合に使います。

```
GET /api/v2/map/view?lat=35.8574&lon=138.9442
```

主な項目です。

| 項目 | 内容 |
|------|------|
| `latitude` `longitude` | 中心の座標 |
| `zoom` | 実際に使われるズーム |
| `maidenhead` | グリッドロケータ |
| `tile` | タイルのURLテンプレート、著作権表示、最大ズーム |
| `mapUrl` `embedUrl` | 地図ページのURL(別タブ用、iframe用) |
| `externalLinks` | Google Maps / OSM / 地理院地図へのリンク |
| `nearby` | 近傍のSOTA/POTAの配列(近い順) |

`nearby` の各要素は次のとおりです。

| 項目 | 内容 |
|------|------|
| `kind` | `sota` または `pota` |
| `code` | リファレンスコード(例: `JA/TK-001`) |
| `name` `nameJ` | 名称(英語、日本語) |
| `latitude` `longitude` | 座標 |
| `distanceM` | 中心からの距離(メートル) |
| `altM` `points` | 標高、ポイント(SOTAのみ) |
| `location` | 所在地。SOTAは市区町村(日本語。複数にまたがる場合は「、」区切り)、POTAは地域 |

## エラー

| 状況 | 応答 |
|------|------|
| `lat` や `lon` がない | 400 `INVALID_QUERY` |
| 範囲外の値(緯度、経度、ズーム、`radius` など) | 422 `VALIDATION_ERROR`(日本語のメッセージ付き) |

近傍の検索に失敗した場合は、エラーにならず、近傍なしで地図だけを返します。

## 注意

- 地図の表示には、ブラウザからインターネット(Leaflet は unpkg、タイルは地理院またはOSM)への接続が必要です。
- POTA公園は、区域の形ではなく、中心の1点との距離で判定します。広い公園は、区域内にいても距離が大きく出ることがあります。
- 非アクティブなPOTA公園は表示しません。
